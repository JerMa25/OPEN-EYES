# 🦯 OPEN EYES - Smart Cane for the Visually Impaired

---

## 📖 Présentation

**OPEN EYES** est un projet de canne intelligente conçue pour améliorer l'autonomie et la sécurité des personnes malvoyantes et aveugles. Le projet combine un dispositif IoT embarqué avec des applications mobiles pour offrir une assistance complète à la navigation et à la sécurité.

### 🎯 Objectif

Permettre aux personnes malvoyantes de se déplacer en toute autonomie et sécurité grâce à un système intelligent qui :
- Détecte les obstacles et les dangers (eau, marches, objets)
- Guide l'utilisateur par des alertes sonores distinctives
- Localise en temps réel via GPS
- Alerte automatiquement les contacts d'urgence en cas de besoin

---

## ⚡ Fonctionnalités Principales

### 🦯 Canne Intelligente
- **Détection d'obstacles** multi-niveaux (haut et bas)
- **Détection d'eau** pour éviter les zones inondées
- **Localisation GPS** en temps réel
- **Alertes sonores** distinctives selon le type de danger
- **Bouton SOS** pour envoi d'alertes d'urgence
- **Détection de chutes** via capteur de mouvement
- **Communication Bluetooth** et SMS/GSM

### 📱 OPEN EYES Navigation
Application mobile pour l'utilisateur de la canne :
- Connexion Bluetooth avec la canne
- Visualisation GPS sur carte
- Navigation vocale
- Configuration des paramètres

### 🆘 OPEN EYES Emergency
Application pour les contacts d'urgence :
- Réception des alertes SOS
- Visualisation de la position en temps réel
- Gestion des contacts d'urgence
- Historique des alertes

---


**Technologies :**
- **Hardware** : ESP32, SIM808 (GPS/GSM), capteurs ultrasoniques, MPU9250 (IMU)
- **Firmware** : C++ (Arduino)
- **Applications** : Flutter (cross-platform)
- **Backend** : Django + PostgreSQL + Redis
